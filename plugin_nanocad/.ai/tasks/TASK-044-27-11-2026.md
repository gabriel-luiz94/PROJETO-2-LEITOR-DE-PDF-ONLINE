# TASK-044 · Usar UTF-8 quando o JSON não informa a codificação DXF

O JSON recebido tem formato `cad-dxf-tags-v1`, versão DXF AC1032, e omite o campo opcional `encoding`. O acesso a um campo ausente devolvia nulo. A comparação com a string vazia o interpretava como codificação desconhecida e interrompia o comando antes de ler o DXF no CAD.

O núcleo agora seleciona UTF-8 para campo ausente, nulo, vazio ou com os marcadores `utf-8` e `utf8`. O marcador `bytes-iso-8859-1` conserva a representação de bytes do DXF legado. Os testes cobrem os marcadores aceitos, o texto acentuado e a recusa de marcação desconhecida.

Para compatibilidade com o plugin 0.18.1, um exportador pode emitir o campo `encoding` com string vazia quando as tags são Unicode e o DXF é escrito em UTF-8.
