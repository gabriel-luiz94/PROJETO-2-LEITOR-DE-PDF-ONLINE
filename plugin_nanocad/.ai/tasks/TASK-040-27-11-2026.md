# TASK-040 — Intercâmbio geométrico CADSuite Web

**Status** — Implementado no plugin 0.17.0. Validação no nanoCAD 5 e 26 pendente.

## Comportamento

- `CSEXPORTAR` exporta as entidades do Model Space em `cad-dxf-tags-v1`. Seções de suporte permanecem no JSON para manter tabelas, blocos e objetos DXF. O conteúdo dos layouts fica de fora.
- `CSIMPORTAR` acrescenta o modelo exportado ao desenho ativo usando a clonagem nativa. Colisões de nome podem renomear definições importadas. Os metadados ligados a entidades seguem a clonagem nativa.
- `CSSUBSTITUIR` clona o modelo recebido e remove o modelo anterior na mesma transação. Exige confirmação e backup DXF. Recusa a operação quando há uma obra do OrçaCore associada ou referências externas conhecidas ao modelo.
- `CSATUALIZAR` exige o JSON derivado de uma exportação do modelo e dependências atuais. Confere handles e edita no lugar linhas, círculos, arcos e polilinhas leves com a mesma quantidade de vértices. Mudanças de layer, metadados, lista de entidades ou definições são recusadas. Exige confirmação e backup DXF.
- A exportação preserva os bytes de DXFs legados no campo de codificação. Operações de entrada recusam registros proxy identificados. O contrato `leitor-obra` permanece independente.
