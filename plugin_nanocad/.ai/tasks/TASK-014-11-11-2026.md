# TASK-014 — Plugin compatível com o nanoCAD 5 (DLL pronta)

## Pedido
"deixe ele compatível com a versão do Nanocad5 que é mais limitada" (junto com TASK-131 do principal).

## Problema
O nanoCAD 5 roda .NET Framework 4 e a API dele (hostmgd/hostdbmgd) não está em pacote nenhum (o NuGet só tem a API do 23 em diante, e em .NET 6).
Até aqui a DLL do 5 só saía compilando no computador do usuário (`build_nanocad5.bat`), e qualquer membro que faltasse na API dele quebrava a compilação.

## Solução
1. **Referências geradas** (`ferramentas/GerarApiNanoCAD5`, Roslyn): compila o plugin contra a API do nanoCAD 26 e coleta CADA tipo/membro usado
   (com bases, operadores, enums, delegates, foreach/using); escreve `src/ApiNanoCAD5/hostdbmgd|hostmgd/*.cs` (só declarações, mesmos
   namespaces/assinaturas). Hoje: 77 tipos, ~180 membros. O `compilar.sh` regenera sempre.
2. **DLL .NET 4** (`src/nanoCAD5/OrcamentoNanoCAD5.csproj`): mesmo código, C# 5, `NANOCAD5`, referências do .NET 4.0 + as geradas
   (as API do nanoCAD não têm assinatura forte e são versão 1.0.0.0: no nanoCAD 5 valem as dele). Saída `appload/nanoCAD5/` + `versao.json`.
3. **`Plugin/Compat.cs`**: um membro que não exista no nanoCAD 5 dá TypeLoadException/MissingMemberException quando o .NET compila o método
   que o usa. Cada recurso opcional fica num método/lambda próprio chamado por `Compat.Tentar`: se faltar, o recurso é desligado (aviso uma vez)
   e o resto segue. Aplicado em:
   - extrator: um leitor por tipo de entidade (MLEADER, LEADER, polilinhas 2D/3D, atributos, blocos dinâmicos, contorno do texto);
   - marcas na tela: gráficos transitórios → vetores temporários do Editor (cruz + linhas);
   - sessão do desenho (UserData → dicionário próprio), janela não modal (→ Show por cima), comando em andamento, zoom (→ comando ZOOM).
4. Versão única em `src/Versao.props` (as duas DLLs e o teste conferem com `VersaoPlugin`).

## Limites
- Não testado num nanoCAD 5 real. Se a DLL nem carregar (ex.: namespaces diferentes na API do 5), `build_nanocad5.bat` compila no computador
  dele contra as DLLs reais e mostra o erro exato (mandar `appload\nanoCAD5\compilacao*.log`).
- `ORC_AJUDA` lista os recursos que ficaram desligados naquele nanoCAD.
