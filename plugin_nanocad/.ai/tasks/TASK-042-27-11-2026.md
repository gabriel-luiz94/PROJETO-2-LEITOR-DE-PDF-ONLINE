# TASK-042 · Integrar os comandos de DXF e JSON no menu OrçaCore

O prefixo `CS` entrava em conflito com a identidade de outro programa. O plugin 0.18.1 usa `ORCACORE` ou `OC` → **Intercâmbio de desenhos** para selecionar as ações. O menu envia o mesmo comando que pode ser digitado no nanoCAD, sem exigir escolher um projeto.

| Comando | Ação |
|---|---|
| `ORC_EXPORTAR_JSON` | Exportar o desenho ativo |
| `ORC_IMPORTAR_JSON` | Acrescentar geometria ao desenho ativo |
| `ORC_GERAR_DXF` | Gerar um DXF separado |
| `ORC_ABRIR_DXF` | Abrir o DXF para conferência |
| `ORC_ATUALIZAR_DESENHO` | Atualizar geometria com backup |
| `ORC_SUBSTITUIR_DESENHO` | Substituir o Model Space com backup |
| `ORC_CONVERSOR_DXF` | Conferir a disponibilidade do conversor |
| `ORC_AJUDA_DESENHO` | Listar os comandos de intercâmbio |

Os antigos comandos `CS` foram retirados do registro do plugin. O formato JSON e o protocolo local com o OrçaCore 2.9.8 permanecem compatíveis.

Validar no nanoCAD 5 e 26 a abertura do submenu e a execução de suas ações.
