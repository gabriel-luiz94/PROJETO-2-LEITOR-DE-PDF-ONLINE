# TASK-020 — Integração com o projeto de trabalho do OrçaCore; sem gravação no banco (0.10.0)

## Pedido
"Realizar a integração. Remover o salvamento no banco pelo plugin" (opções 1+2+3+4 da análise da estrutura de projeto da TASK-154/158).

## Como ficou
1. **Um projeto por desenho, no mesmo arquivo**: o Salvar grava `<desenho>.obra` (pasta do desenho) no formato do 📁 Projeto do OrçaCore.
   | Parte | Quem manda |
   |---|---|
   | `dados` (linhas de Cabos e Outros) e `cad` (a obra do plugin) | o desenho (plugin) |
   | `projeto_trabalho.sap` e `.resultado` | o OrçaCore |
   | `projeto_trabalho.nome` e `.numero_obra` | os dois |
   O OrçaCore preserva a `cad` ao gravar (TASK-162 do principal). O plugin guarda `cad.assinaturaLinhas`; se as linhas do arquivo forem outras
   (editadas no Resumo do programa) ou o arquivo for um projeto só do programa, pergunta antes de gravar por cima.
2. **🌐 Abrir na aplicação**: salva o projeto e entrega o caminho ao OrçaCore deste computador — aberto: a janela vem para a frente e abre o
   projeto (Abrir/Mesclar/Sobrescrever se a tela já tem dados; se já é o projeto aberto, relê); fechado: abre o `.exe` com `--abrir-projeto`.
   **Nada é gravado no banco** (removidos `EnviarObra` e `POST /api/plugin/obra`). Sem o programa instalado, o projeto fica na pasta do desenho.
3. **Nome e número de obra** no plugin (`ORC_PROJETO`, botão no painel, perguntados no primeiro Salvar); o painel mostra "obra nº …".
4. **Nome OrçaCore** nos textos do plugin.

## Compatibilidade
- Continuar obra salva: `<desenho>.obra` (se tiver `cad`) → cópia no DWG → `<desenho>.obra.json` antigo.
- OrçaCore antigo (sem receber projetos) responde 422: o plugin avisa para atualizar o programa.
