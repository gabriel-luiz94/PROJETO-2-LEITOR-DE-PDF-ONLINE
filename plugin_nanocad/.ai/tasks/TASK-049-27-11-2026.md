# TASK-049 · Aplicar patches incrementais com menos etapas

O comando `ORC_SINCRONIZAR_JSON` exportava o desenho ativo para validar, exportava outro DXF para backup e capturava o desenho novamente para revalidar. A sequência passa a usar uma única captura no comando modal. A confirmação continua mostrando as quantidades. A escrita no DWG continua em uma transação, com a conferência dos handles antes de escrever.

O planejador copia apenas as listas de registros que o filtro de Model Space altera. Ele reutiliza a verificação de `sourceModel` e percorre as referências do desenho uma vez, mesmo com várias exclusões. A leitura DXF auxiliar do patch permanece.

O comando incremental não solicita arquivo de backup. Os comandos de substituição e atualização integral continuam com o fluxo próprio. Validar o tempo total e o desfazer no nanoCAD.

No arquivo de teste com 8 inclusões e 7 exclusões, a mediana de três execuções do planejador caiu de 2.957 ms para 498 ms, com o JSON já carregado. A medição cobre o núcleo, sem execução do nanoCAD.
