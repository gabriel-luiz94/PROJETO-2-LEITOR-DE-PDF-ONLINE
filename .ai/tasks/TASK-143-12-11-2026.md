# TASK-143-12-11-2026

**"Abrir na aplicação" do plugin do nanoCAD abre a obra no GridReader instalado (não mais numa aba do navegador)**

## Status
CONCLUÍDA em 2026-11-12 (no Windows: aguardando teste com o .exe e o nanoCAD). Plugin: TASK-016 (0.8.0).

## Pedido
"O plug-in está abrindo uma aba no navegador com a aplicação nele. Quero que ele identifique o executável aberto e transfira para ele os dados ao
clicar na aplicação. Caso a aplicação esteja fechada ele abre a aplicação e carrega os dados."

## Como funciona
1. **Registro:** ao abrir, o .exe grava `%APPDATA%\OrcamentoNanoCAD\programa.json` (`exe`, `porta`, `versao`, `pid`) — `programa_local.registrar`.
2. **Programa aberto:** o plugin chama `GET http://127.0.0.1:<porta>/api/plugin/desktop` ("GridReader", `desktop: true`) e entrega
   `POST /api/plugin/receber {chave, envelope}`.
   - Sem login (o plugin não tem o token deste programa), mas **só no programa instalado** (`APP_MODE=desktop`) e **só do próprio computador** (127.0.0.1).
   - A obra fica em memória por até 1 h (`PENDENTES`); a janela é levada para `/resumo?plugin_pendente=<id>` e trazida para a frente
     (`janela_desktop.mostrar`: `load_url`, `restore`, `show`, `on_top`; o plugin chama `AllowSetForegroundWindow` antes).
   - O Resumo (`receberObraDoPlugin`): sem login → login e volta; com login → `GET /api/plugin/pendente/<id>` → `POST /api/plugin/obra`
     (grava como obra particular do usuário, como antes) → abre pelo link `?obra=…`.
3. **Programa fechado:** o plugin grava `{chave, envelope}` em `%APPDATA%\OrcamentoNanoCAD\obras_para_abrir\obra_<data>.json` e abre o .exe com
   `--abrir-obra "<arquivo>"`; o .exe lê, apaga o arquivo, guarda a obra e começa em `/login?new_session=1&next=/resumo?plugin_pendente=<id>`.
4. **Sem programa instalado** (sem `programa.json` ou sem o .exe): o caminho antigo — aplicação do ORC_CONECTAR, no navegador.

## Testes
- `tests/test_plugin_programa_local.py` (5): apresentação, entrega + janela + pendente com login + gravação, só desktop/só local, arquivo do .exe, ligações.
- Plugin: `ProgramaLocalTests` (3).
- Ponta a ponta no Chromium: entrega → login → volta → obra gravada e aberta no Resumo (7 cabos, 8 outros), sem erros no console.

## Observações
- O registro (`programa.json`) é feito pelo .exe ao abrir: depois de atualizar, abra o GridReader uma vez para o plugin achá-lo fechado.
- Trazer a janela para a frente depende do Windows (às vezes ela só pisca na barra de tarefas).
