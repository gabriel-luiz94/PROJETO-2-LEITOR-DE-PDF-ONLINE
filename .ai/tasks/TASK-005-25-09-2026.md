## Objetivo

Separar por projeto os itens salvos: obras salvas, RECs salvos, regras de IA (aprendizado) e
regras do leitor de PDF/DXF.

## Contexto

Hoje todos os itens salvos ficam visíveis em todos os projetos. O ideal é que cada item fique
disponível apenas no projeto em que foi salvo.

## Situação atual

Se o usuário salva uma obra do projeto Rondônia, ela também aparece quando ele está no projeto
Paraíba. O mesmo ocorre com os RECs salvos.

## Comportamento desejado

As obras salvas no projeto Rondônia ficam disponíveis apenas no projeto Rondônia; o mesmo vale
para RECs, regras de IA e regras do leitor.

## Restrições

Lógicas de salvamento, lógica de cálculo, etc. (não alterar).

## Critérios de aceite

Ao salvar uma obra do projeto Rondônia, ela não aparece quando o usuário está no projeto Paraíba.

## Exemplos

### Entrada

Salvei a obra 1 no projeto Paraíba.

### Resultado esperado

Ao selecionar o projeto Rondônia, ela não aparece.

## Implementação (2026-09-25)

Implementado exatamente como planejado, com uma correção descoberta durante o teste end-to-end da
TASK-006 (ver detalhes lá): **o valor de backfill/`DEFAULT` usado é o código do projeto (`"229"`
para RONDÔNIA), não o nome `"RONDONIA"`**. O nome não é a chave técnica usada em nenhum lugar do
app para agrupar por projeto — `regras_conversao.projeto_codigo` e
`localStorage['projeto_selecionado_codigo']` (o valor que o frontend efetivamente envia em toda
chamada) sempre usam o código (`"027"`/`"229"`). Usar o nome como default teria feito as obras/
RECs antigas (com `projeto='RONDONIA'`) nunca aparecerem junto com as novas (`projeto='229'`) —
seria a mesma classe de inconsistência silenciosa já vista antes neste projeto. Corrigido em:
- `database.py` — `ALTER TABLE ... DEFAULT '229'` (obras, historico_rec, regras)
- `scripts/schema_supabase.sql` — mesmo ajuste
- `models.py` — `ObraModel`, `RecModel`, `RecSaveRequest`, `RegraModel`, `ChatRequest`
- `static/resumo.js`, `static/script.js`, `static/resultado_orcamento.html` — fallback
  `|| '229'` em vez de `|| 'RONDONIA'` nos pontos que enviam `projeto`/`projeto_codigo`

**Alterado:**
