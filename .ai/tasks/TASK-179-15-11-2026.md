# TASK-179 — Guia e modelo para quem cria uma base nova

**Status:** CONCLUÍDA (15/11/2026) — ADR-007

## Objetivo

Baixar a barreira para outra equipe escrever a própria base: um guia curto da sintaxe, uma base-modelo comentada, um projeto de
exemplo pronto e mensagens do validador que apontam para o guia.

## Contexto

- Sintaxe atual: declaração `N=N(p=padrão), apelido`; grupos `N(p=cond)` com `%`, `|`, `!=`; grupos que chamam ativos e compostos
  `N(cabo=%):=3*ALCA(cabo)` (TASK-110/134); parâmetros fechados; `OBRA.*` (TASK-165); colunas LV, FATOR I/R, ARRED.
- Documentação espalhada em tarefas e em `data/manual_regras_e_ajustes.md`; a ficha da base (`static/base_ficha_*.js`) mostra a linha,
  mas não explica a regra em português.
- Armadilhas reais que só o autor conhece: mesmo código duas vezes no mesmo grupo (fica um só), padrão de parâmetro sem grupo que o
  cubra, valor não cadastrado recusando o ativo inteiro, grupo geral com valores que deveriam estar num grupo com condição (caso
  CE_2_TR com dois trafos).

## Comportamento desejado

1. `docs/base_guia.md` (até ~4 páginas): do simples ao avançado, cada recurso com um exemplo de 3–5 linhas e o resultado
   (estrutura simples → com parâmetro → grupo → linha viva → retirada → composto → `OBRA.*`), e a seção "armadilhas".
2. `data/pacotes/exemplo/`: base pequena (10–15 ativos: poste, N1, N3, N4, cabo, CON, ALCA) + vinculação + 5 casos de referência,
   que importa e funciona sozinha. É o ponto de partida sugerido para projeto novo.
3. Ficha da base: cada linha ganha a frase em português ("vale quando cabo contém A35P; soma 3 de 2461009 na instalação").
4. Validador: cada tipo de erro/aviso com um código curto (`B-012`) e o link para a seção do guia.
5. Aviso novo (heurística): item de catálogo de equipamento (trafo, chave, religador) no grupo **geral** de um ativo que tem parâmetro
   do mesmo tipo (`trafo`) → "este item vale para todo pedido; não deveria estar no grupo do parâmetro?" (pegaria o caso CE_2_TR).

## Restrições

- Não muda a sintaxe da base nem o cálculo.

## Critérios de aceite

- [x] Uma pessoa sem contato com o projeto importa o pacote de exemplo e orça uma obra seguindo só o guia.
- [x] Ficha explica em português grupos, compostos e linha viva.
- [x] A base `base_orcamento_20261115_CON_EMB.csv` (antes da correção) gera o aviso do item 5 para CE_2_TR; a `…_TT.csv` não.
