# TASK-128-10-11-2026

**Desktop: janela sem "recusou a conectar", campos de chave fora das heurísticas de senha, telas abertas dentro do programa e dica sem falso "não encontrado"**

## Status
CONCLUÍDA em 2026-11-10

## Pedido / diagnóstico
1. O navegador colava o e-mail do login em outras telas e pedia para salvar a senha: as chaves de API (Resumo, CloudConvert) e a senha de usuário novo (admin) eram `type="password"`.
2. Ao abrir o programa aparecia "recusou a conectar" (sumia ao atualizar): a janela abria antes de o servidor aceitar conexões (uvicorn só abre a porta depois do startup — teste de rede, banco, nuvem).
3. Ao digitar "(" aparecia "ativo não encontrado" e depois funcionava: `AtivoDica.atualizar` só esperava a base na primeira tecla; enquanto a requisição estava em andamento (`carregando`), as teclas seguintes desenhavam a dica com a base vazia. A base só era pedida no 1º "(" e `/api/orcamento/dados` demora no início (sincroniza com a nuvem).
4. "Montar Orçamento" abria nova aba do navegador (`window.open(..., '_blank')` → no pywebview vai para o navegador do sistema). Pedido: tudo dentro da aplicação, resultado na mesma tela.

## Entrega
- `services/inicio_janela.py` + `app.py`: a janela abre com a tela "Iniciando…" (`html=`) e `win.load_url(login)` só quando a porta responde (`esperar_servidor`, até 90 s; tela de erro se não subir).
- `static/campos_segredo.js` (novo): `<input class="campo-segredo">` vira texto mascarado (`-webkit-text-security`, `autocomplete="off"`); sem suporte a esse CSS (Firefox/online) volta a `password` + `new-password`. Aplicado em `input-apikey*` (resumo.html), `input-cloudconvert-key` (index.html) e `newPassword` (admin.html; `newEmail` com `autocomplete="off"`). `login.html` ganhou `autocomplete="username"/"current-password"`.
- `static/ativo_dica.js`: base vazia → não desenha nada (fecha a caixa) e pede a base uma vez; `resumo.js`: `carregarBaseOrcamento()` (promessa única) é chamada JÁ ao abrir a tela.
- `static/abrir_na_app.js` (novo): `AbrirNaApp.abrir(url, titulo)` = tela cheia por cima da página atual (iframe + botão Fechar/Esc; o Resumo de baixo não é descarregado), `navegar(url)` = mesma janela, `voltarOuFechar()` para o botão Voltar das telas abertas em moldura. Na versão online (`/api/version` → `server`) continua abrindo nova aba. Usos: Montar Orçamento (`/resultado_orcamento`), botão Tabela de orçamento (`/orcamento`), Manual (painel de regras) e Leitor → Resumo (`navegar`). `resultado_orcamento.html` e `orcamento.html`: Voltar fecha a moldura.
- Rotas sem cache para os 2 JS novos (`app.py`). Testes: `tests/test_app_desktop_128.py` (7). Conferido no Chromium: base pedida ao abrir, nenhuma caixa enquanto carrega, caixa certa depois; campos de chave mascarados; resultado abre em moldura sem nova aba e o Voltar fecha a moldura.

## Observações
- O login continua com `type="password"` (o navegador do programa ainda pode oferecer salvar a senha ali); só os campos que não são login saíram das heurísticas de senha.
- Para valer no .exe é preciso publicar uma versão nova.
