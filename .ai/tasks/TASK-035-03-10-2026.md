# TASK-035-03-10-2026

**Filtro por projeto no histórico do modo autônomo**

## Objetivo

Permitir filtrar o histórico de execuções da tela `/autonomo` por projeto, além do filtro de status que já existia, para viabilizar conferir em lote vários projetos rodados pelo modo autônomo.

## Contexto

Pedido do usuário (2026-10-03) depois de discutirmos uma estratégia para rodar vários projetos pelo modo autônomo (TASK-031) e só depois ir conferindo. Confirmei no código que a arquitetura já suporta múltiplos projetos numa única instância: `entrada/<código-do-projeto>/arquivo.dxf` — a vigia (`services/autonomo/pasta.py`) varre todas as subpastas automaticamente, um arquivo por vez (trava global). Mas o histórico (`GET /api/autonomo/execucoes`) só filtrava por `status`, misturando execuções de todos os projetos — inviável de triar visualmente num lote grande.

## Situação atual (antes desta tarefa)

- `services/autonomo/execucoes.py:listar(status=None, limite=100)` — só filtro de status.
- `routers/autonomo.py:listar_execucoes` — só repassa `status`/`limite`.
- `static/autonomo.html` — só `<select id="filtro">` (status).
- `static/autonomo.js` — `atualizar()` monta a query só com `status`.

## Comportamento desejado

- Novo parâmetro `projeto` em `execucoes.listar()`, na rota `GET /api/autonomo/execucoes` e combinável com `status` (os dois filtros aplicam juntos, como um `AND`).
- Novo `<select id="filtro-projeto">` na tela, ao lado do filtro de status, populado a partir de `GET /api/projetos` (todos os projetos cadastrados, não só os que já têm execução — mesma fonte que a tela Resumo usa para o seletor de projeto).
- Trocar o filtro de projeto (ou de status) recarrega o histórico e a lista de pendências de confirmação com os dois filtros aplicados.

## Restrições

- [x] Nenhum dos contratos listados em `RULES.md` (Regra 5)
- Não mudar o comportamento de `GET /api/autonomo/execucoes` sem `projeto` informado (continua idêntico a antes).

## Critérios de aceite

- [x] `execucoes.listar(status=None, projeto=None, limite=100)` filtra por projeto isoladamente, por status isoladamente, pelos dois juntos, e sem nenhum (lista tudo).
- [x] `GET /api/autonomo/execucoes?projeto=<codigo>` funciona pela rota HTTP real (não só na função Python).
- [x] A tela `/autonomo` mostra o novo seletor, populado com os projetos cadastrados, e filtra a tabela/pendências ao trocar a seleção.
- [x] Nenhum erro de JS no console ao carregar a tela ou trocar os filtros (verificado com Playwright).
- [x] Documentação `.ai` atualizada conforme `RULES.md` Regra 9
- [x] `STATE.md` atualizado conforme `RULES.md` Regra 10
