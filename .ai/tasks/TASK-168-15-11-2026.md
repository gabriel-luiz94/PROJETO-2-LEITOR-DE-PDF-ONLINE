# TASK-168 — O programa sempre abre no projeto default

**Status:** CONCLUÍDA (15/11/2026)

## Objetivo
Por padrão o programa abre sempre no **projeto default**; o usuário abre o projeto (Projeto → Abrir).

## Situação anterior
O projeto aberto fica em `localStorage['gridr_projeto']`. O programa instalado usa perfil persistente do navegador embutido (`private_mode=False`, porta fixa 8000), então o projeto da execução anterior voltava sozinho ao abrir o programa.

## Implementado
- `middleware/nocache_middleware.py`: `SESSAO_ID` (uuid gerado na partida do servidor) e cookie `gridr_sessao` nas respostas HTML — só no programa instalado (`APP_MODE != "server"`); a versão online não muda.
- `static/projeto.js`: `reiniciarNoDefault(cookie, storage)` roda antes de qualquer leitura do estado: se o id da abertura mudou desde a última vez, esquece `gridr_projeto` e guarda o novo id. Recarregar a tela ou trocar de tela na MESMA execução mantém o projeto aberto.
- O rascunho do projeto default e o "Abrir projeto" do plugin (`--abrir-projeto`) seguem como estavam (o projeto do plugin abre depois do reinício).

## Testes
`tests/test_abre_no_default_168.py` (cookie só no desktop, id estável, JS) + e2e Playwright (abre no default, usuário abre, recarregar mantém).
