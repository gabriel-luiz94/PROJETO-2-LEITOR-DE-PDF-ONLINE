# TASK-178 — Casos de referência por projeto: conferência automática da base

**Status:** CONCLUÍDA (15/11/2026) — ADR-007

## Objetivo

Cada projeto guarda um conjunto de **pedidos com o resultado esperado**. Ao importar ou editar a base (ou a vinculação), o programa roda
os casos e mostra o que mudou, antes de gravar. Quem cria a própria base passa a saber se quebrou algo.

## Contexto

- Hoje a conferência é manual (ex.: antes × depois da base CON_EMB/TT feito fora do programa, 312 pedidos no `processar_calculo`).
- `validar_base` só olha a sintaxe; não vê "o N4 passou a sair sem cartucho" nem "o CE_2_TR saía com dois trafos".
- Para Pernambuco, a ICP pode gerar os resultados esperados (habilidade `orcamento-icp-neoenergia-pe`, `icp_orcar.py`).

## Comportamento desejado

1. **Caso:** `{nome, pedidos: [{ativo, operacao}] | obra (.obra), obra_cabecalho, modo, esperado: [{codigo, qtd}], tolerancia, origem}`.
   `origem`: "gravado do programa" | "ICP" | "manual".
2. **Gravar:** na tela do resultado, "Guardar como caso de referência" (salva o pedido e o resultado atual).
3. **Rodar:** botão "Conferir base" e, automaticamente, na pré-visualização da importação da base e da vinculação: tabela
   caso × (igual / mudou / erro), com o detalhe código a código (antes → depois), como o relatório `CON_EMB_mudancas.md`.
4. **Aceitar mudanças:** marcar casos como "mudança esperada" atualiza o `esperado` (com nota de quem e por quê).
5. Casos fazem parte do pacote de projeto (TASK-177).
6. Desempenho: rodar em lote no servidor, com progresso, reaproveitando a base já carregada (medir o tempo de 300 casos e anotar
   aqui; a conferência manual de 312 pedidos × 2 bases levou vários minutos carregando a base a cada pedido).

## Restrições

- Não muda o cálculo. Casos são por projeto.
- Schema do Supabase: tabela nova `casos_referencia` (marcar no RULES).

## Critérios de aceite

- [x] Gravar 3 casos, trocar a base por uma com um código a menos num ativo: a pré-visualização da importação mostra os casos que mudaram, com o código.
- [x] Marcar "mudança esperada" atualiza o caso.
- [x] Casos exportados e importados com o pacote.
