# TASK-230 — Pacote de entrega do OrçaCore

**Status:** IMPLEMENTADA (23/11/2026)

## Pedido
Script para mandar o OrçaCore com o `.env` e o banco a um usuário, garantindo que ele consiga usar de cara.

## Decisões
- Nada pessoal vai (usuários/sessões/chaves/obras/históricos); o que vai é a base de orçamento (a que a conta de origem enxerga) e as regras/configurações de projeto.
- O «de cara» é verificado, não presumido: o script abre o app sobre uma cópia e testa login/base antes de concluir.
- A senha viaja por outro canal; o `.env` não a contém (ADMIN_PASSWORD de reserva aleatório, para o banco recriado nunca cair em `admin123`).
- Windows: `Instalar.bat` instala o Setup em silêncio (sem administrador), guarda banco anterior e copia os dados. **Não testado em Windows** (o .bat foi revisado, mas só roda lá).

## Pendências / ideias
- Validar o `Instalar.bat` numa máquina Windows limpa (antivírus/SmartScreen).
- Assinar o instalador; zip com senha (o `zipfile` do Python não cria zip protegido: usar 7-Zip no envio).
