# TASK-158-13-11-2026

**Salvar / Salvar como / salvamento automático (ligado-desligado) e rascunho do projeto default**

## Status
CONCLUÍDA em 2026-11-13 — conferida no Chromium (ponte do pywebview simulada chamando o código Python real, Resultado em moldura); NÃO conferida no `.exe`/WebView2 (caixas nativas e o aviso ao fechar a janela, `beforeunload`).

## Pedido
O usuário (único usando o arquivo) viu "não gravado — arquivo alterado por fora" e pediu para decidir quando o projeto é salvo: botões Salvar e Salvar como e um salvamento automático que pode ser ligado ou desligado. Escolheu a **opção B** (botão dividido "Salvar ▾" + chave + etiqueta de estado).

## Regras (decisões do usuário)
- Projeto **novo**: automático LIGADO. Projeto **aberto**: DESLIGADO. Projeto **default**: ligado e gravando um **rascunho** para recuperar depois (arquivo fixo junto do aplicativo: `rascunhos/rascunho_default.obra` + `rascunho_default_anterior.obra` da sessão anterior; menu "Recuperar rascunho do default…").
- No default, Salvar ou Salvar como abrem direto "Novo projeto" (o que está na tela vai para o projeto, com o automático ligado).
- Ligar a chave com pendências grava na hora. Desligada, nada é gravado até Salvar (Ctrl+S) — Resumo, Resultado (inclusive edições), SAP e nome/número.
- Voltar ao default, abrir outro projeto ou criar um novo com pendências e o automático desligado: pergunta "Salvar alterações em …?" (Salvar / Não salvar / Cancelar); `beforeunload` avisa ao fechar a janela.
- Salvar como: grava uma cópia (Resumo, resultado, SAP) com outro nome/pasta e passa a trabalhar nela; mantém a chave como estava; o arquivo antigo não é tocado.

## Entrega
- `static/projeto.js`: barra `📁 projeto · [💾 Salvar | ▾] · etiqueta` (Salvo às hh:mm · automático ligado / Não salvo / Gravando… / Rascunho gravado às … / "Arquivo alterado por fora — clique para resolver"); menu ▾ (Salvar, Salvar como, chave de salvamento automático, Novo, Abrir, Propriedades, Recuperar rascunho, Voltar ao default); `salvar`, `definirAuto`, `confirmarSaida`, `gravarRascunho`, `recuperarRascunho`; `estado.auto`; Ctrl+S / Ctrl+Shift+S; o Resultado registra um coletor (`__registrarColetor`) para o Salvar pedir as linhas atuais e as edições pendentes voltam ao reabrir a moldura (`__pendenteResultado`).
- Correção da corrida que dava o alarme falso "alterado por fora": a assinatura do arquivo agora é sempre gravada sobre o estado ATUAL (`atualizarEstado`), nunca sobre uma cópia lida antes da gravação. Com o automático desligado não há gravação em segundo plano, então o aviso só pode aparecer ao clicar em Salvar.
- `services/projeto_desktop.py`: `rascunho_gravar` (a primeira gravação da sessão guarda o atual como anterior; exige o código do projeto de regras), `rascunho_info`, `rascunho_ler`; ponte `projeto_rascunho_gravar|info|ler`.

## Limites conhecidos
- O rascunho do default só é gravado quando há dados no Resumo (nunca a tela vazia por cima do rascunho); fica com 2 versões (atual e da sessão anterior).
- "Salvar Obra" (botão antigo, grava no banco/nuvem) continua existindo e é outra coisa.
