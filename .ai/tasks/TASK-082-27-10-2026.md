## Objetivo
Criar do zero as tabelas de Processamento e Classificação do Leitor para Pernambuco (editáveis na tela depois). Nesta entrega: **postes** e **cabos**; estruturas e demais itens ficam para a próxima.

## O que o usuário definiu
- **PDF:** todo texto sai em preto; a operação vem de **onde o item está**: dentro da bolha, fora dela ou riscado.
- **DXF:** operação pela layer `01_INSTALAR`, `01_REMOVER`, `01_REAPLICAR`. Cores: RGB 000 = instalar, RGB 001 = remover; reaplicar só pela layer.
- **Poste:** `11300D` = altura 11 + esforço 300 + tipo (D = DT duplo T, R = RC circular concreto, FV = fibra). Equivale a `DT11/300`.
- **Cabo:** a anotação é a coluna **LABEL** das tabelas de cabos (MT monofásico, MT trifásico, BT); o comprimento vem na mesma linha ou na imediatamente abaixo.
- Regras começam do zero e seguem editáveis pela tela.

## Como o sistema é hoje (limites encontrados)
1. **Cor:** o motor classifica em VERMELHO / CINZA / AZUL / OUTRA e "PRETO" é "qualquer coisa que não seja vermelho nem cinza". **RGB 000 e RGB 001 são indistinguíveis** hoje. No DXF a layer resolve; a cor exata exigiria uma condição nova.
2. **Bolha / fora / riscado não existem no motor:** a extração do PDF (`services/pdf_service.py`) devolve só texto + cor (+ página). É preciso extrair **geometria** (desenhos da página) e marcar cada texto como `BOLHA`, `RISCADO` ou `FORA`, e o motor ganhar uma condição nova (`marca_em`), como já tem `cor_em`/`layer_em`. Precisa de um **PDF real** para calibrar.
3. **Comprimento na linha de baixo:** o motor tem "vizinhança" (regex num texto próximo, janela N) que serve para isso, mas hoje só dentro das regras da fase 3.
4. O formato de linha de Cabos é `ATIVO FASE COMPRIMENTO` (ex.: `CAA2 3 45`).

## Proposta
**Postes** (fase 1, ordem 10–19): `^(\d{1,2})(\d{3})(D|R|FV)$` ou 4 dígitos de esforço → ativo `1-DT{altura}/{esforço}` (D→DT, R→RC, FV→FV) — ou compacto `11300D` se preferir. Classificação: `^1-(DT|RC|FV|CV)\d+/\d+` → POSTE. Ajustar a classificação antiga que só conhecia DT|CV.
**Operação:** PDF `BOLHA`/`FORA`/`RISCADO` → I/R/M (falta o mapeamento); DXF por layer (`01_INSTALAR`→I, `01_REMOVER`→R, `01_REAPLICAR`→M?).
**Cabos:** reconhecer o LABEL: `^(\d)x…` (1x/2x/3x = fases), código do cabo (S1/0, S04, SA4/0, C16, C95, …), tensão opcional (`-7,9kV`, `-13,8kV`, `+20kV`), BT (`1xC16(16)`, `RAMA25`, `PB35`), neutro entre parênteses/colchetes (`(S04)`, `[C16]`).

## Decisões já dadas (conversa de 2026-10-27)
1. **Não alterar o código do Leitor** (complexo). Sem geometria (bolha/fora/riscado). A operação vem da **layer** (DXF) e, como reserva quando a layer não vier, da **cor RGB lida** — calibrando os tons de preto (000 = instalar, 001 = remover). Reaplicar só pela layer.
2. **Operação M** (reaplicar): a linha é classificada como M e **cada elemento que não seja CABO recebe o prefixo `R-`** (a ser confirmado o formato exato — ver perguntas).
3. **Poste sai no formato compacto**, como aparece escrito (`11300D`); a regra só identifica como POSTE.
4. **Cabo:** a tensão é ignorada; `3x`/`3X` = quantidade de fases; sem prefixo = `1x` implícito.
5. **Neutro** é ligado ao cabo, mas na decomposição para a Totalizadora vira um elemento à parte: `3xA35P(7,94)-13,8kV` → `A35P` qtd 3 + `CAZ7,94` qtd 1; `3xC16(16)` → 3 `C16` + 1 `C16`. A **tabela Cabos do Resumo** passa a aceitar essa notação (dois formatos, como Outros) — ver TASK-083.
